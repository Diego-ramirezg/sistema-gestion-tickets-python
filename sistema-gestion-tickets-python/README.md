# 🎫 Sistema de Gestión de Tickets

Sistema de gestión de tickets desarrollado en **Python**, orientado a la administración de incidencias y requerimientos de una mesa de ayuda.

El proyecto permite registrar, consultar, actualizar y eliminar tickets, manteniendo la información almacenada en un archivo JSON.

---

## 🚀 Funcionalidades

- 🔐 Inicio de sesión de usuarios.
- 🎫 Creación de tickets.
- 📋 Listado de tickets registrados.
- 🔄 Actualización del estado de los tickets.
- 🗑️ Eliminación de tickets.
- 🏷️ Clasificación entre incidentes y requerimientos.
- 📌 Gestión de categorías.
- ⚡ Gestión de prioridades.
- 💾 Persistencia de información mediante JSON.
- 🔢 Generación automática de códigos para tickets.
- 🔒 Encriptación de contraseñas mediante SHA-256.
